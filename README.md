Program Data Mahasiswa Java

Deskripsi
Program ini dibuat menggunakan bahasa pemrograman Java untuk memasukkan dan menampilkan data mahasiswa berupa nama, NIM, dan nilai. 
Program akan menentukan status kelulusan mahasiswa secara otomatis berdasarkan nilai yang dimasukkan.

Fitur Program
- Memasukkan data tiga mahasiswa.
- Menampilkan nama, NIM, dan nilai mahasiswa.
- Menentukan status kelulusan secara otomatis.
- Menampilkan status Lulus atau Tidak Lulus.

Penjelasan Program
Program ini menggunakan class `Mahasiswa` untuk menyimpan data mahasiswa dan class `Main` untuk menjalankan program.
Data mahasiswa dimasukkan melalui keyboard menggunakan `Scanner` dan disimpan dalam array.

Perulangan `for` digunakan untuk memasukkan data tiga mahasiswa. Sementara itu, percabangan `if-else` digunakan untuk menentukan status kelulusan. 
Jika nilai mahasiswa minimal 60, statusnya Lulus. Jika nilai kurang dari 60, statusnya Tidak Lulus.

Cara Menjalankan
Pastikan Java JDK sudah terpasang di komputer.

1. Simpan kode dengan nama `Main.java`.
2. Buka terminal pada folder program.
3. Jalankan perintah berikut untuk compile:

   `javac Main.java`

4. Jalankan program dengan perintah:

   `java Main`

Kesimpulan
Program ini membantu pengguna memasukkan dan menampilkan data mahasiswa serta menentukan status kelulusan secara otomatis. 
Program ini juga menjadi latihan untuk memahami class, object, constructor, array, perulangan, percabangan, dan penggunaan Scanner dalam Java.
